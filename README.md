### Sobre mim

Construo sistemas e aprendo suas falhas. Estudo Ciência da Computação e minha base está na cibersegurança, transitando entre segurança ofensiva e defensiva (Blue Team, SOC, detecção de ameaças, testes de vulnerabilidade): escrevo regras de detecção em SIEM, simulo técnicas mapeadas no MITRE ATT&CK e busco entender o mesmo problema pelos dois lados.

Desenvolvimento full stack é uma ferramenta que uso pra isso. Construo aplicações web do zero, do backend às APIs até o frontend, porque entender como um sistema é feito é o que me permite entender como ele quebra. Inteligência Artificial e Machine Learning entraram nesse caminho da mesma forma: estudo redes neurais e arquiteturas como RAG tanto pra usá-las quanto pra atacá-las e defendê-las.

O que me move é entender a engenharia por trás das coisas até o ponto de conseguir refazê-la, ou derrubá-la.
